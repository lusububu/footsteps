Footsteps, installable app
==========================

Upload everything in this folder to any HTTPS web host (for example GitHub Pages), open the address on your phone,
then add it to the home screen. After the first start it works without a connection.

Files
  index.html              the app
  manifest.webmanifest    name, icon, full screen, landscape
  sw.js                   offline copy of the app (raise VERSION in it after changing any file)
  icon-*.png, apple-touch-icon.png
